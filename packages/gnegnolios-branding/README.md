# GnegnoliOS Branding

This package contains every graphical asset used by the distribution.

Canonical assets are installed under:

```
/usr/share/gnegnolios/
```

Platform integration files may also be installed under standard desktop paths such as:

```
/usr/share/color-schemes/
/usr/share/konsole/
/usr/share/wallpapers/
```

## Current content

- Wallpapers
- Logos
- Design tokens
- KDE color scheme
- Konsole color scheme

## Planned content

- Cursor theme
- Plymouth theme
- GRUB theme
