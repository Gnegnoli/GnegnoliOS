# GnegnoliOS Installer Config

This package installs the GnegnoliOS Smart Installer catalog.

Installed path:

```
/usr/share/gnegnolios/installer/catalog.yaml
```

Resolver command:

```
gnegnolios-installer-resolve --mode express
gnegnolios-installer-resolve --profile development --choice browsers=firefox
```

The source file remains:

```
config/installer.yaml
```
