# GnegnoliOS Calamares Config

This package installs the first-pass Calamares configuration, GnegnoliOS branding component, and live-session launcher.

Installed paths:

```
/etc/calamares/settings.conf
/etc/calamares/modules/packages.conf
/etc/calamares/branding/gnegnolios/
/usr/bin/gnegnolios-install
/usr/share/applications/gnegnolios-install.desktop
```

Calamares itself is not in the official Arch repositories in this environment, so it must be supplied later through the GnegnoliOS repository or an explicit bootstrap step.
