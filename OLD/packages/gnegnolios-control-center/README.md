# gnegnolios-control-center

Packages the Gnegnoli Control Center app (source: `applications/control-center/`)
for GnegnoliOS.

Installs:

- `/usr/share/gnegnolios-control-center/` — the PyQt6 app
- `/usr/bin/gnegnoli-control-center` — launcher script
- `/usr/share/applications/gnegnoli-control-center.desktop` — menu entry

Once installed, the app always appears in the desktop's application menu
under System / Settings; no manual launch needed.
