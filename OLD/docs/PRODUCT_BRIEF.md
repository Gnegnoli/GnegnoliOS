# GnegnoliOS Product Brief

## Mission

GnegnoliOS is a premium Linux distribution based on Arch Linux. The goal is not to create another generic Arch derivative, but a complete operating system with a strong identity, curated defaults, and a product experience that feels mature, professional, and deliberate from the first boot.

Core philosophy:

- Power.
- Elegance.
- Darkness.
- Precision.

The distribution should feel like it was built by a large technology company: solid, trustworthy, restrained, and visually unmistakable.

## Target Users

- Developers
- Power users
- System administrators
- Musicians
- Content creators
- Streamers
- Video editors
- Programmers
- Linux enthusiasts
- Enterprise users

## Technical Baseline

- Base distribution: Arch Linux
- Package manager: pacman
- AUR helper: yay
- Kernels: linux and linux-lts
- Desktop environment: KDE Plasma
- Display server: Wayland
- Display manager: SDDM
- Filesystem: BTRFS
- Snapshots: Snapper
- Bootloader: GRUB
- Init system: systemd
- Firewall: ufw
- Flatpak: enabled
- Audio stack: PipeWire

## Out Of Box Scope

The installed system should be useful without manual setup for:

- Drivers and firmware
- Codecs
- Gaming
- Development
- Editing and multimedia
- Office work
- Containers
- Virtualization
- Backups and snapshots
- Power management
- Security and privacy
- Networking

## Visual Direction

The brand language combines corporate minimalism, gothic architectural geometry, forged steel, volcanic stone, black marble, restrained dark fantasy atmosphere, and luxury industrial product design.

It may reference:

- Dark Souls and Blasphemous, for atmosphere only
- Diablo IV UI, for depth and material treatment only
- Apple industrial design
- IBM enterprise clarity
- Fractal Design minimalism
- Audi Black Edition and Mercedes AMG Night Package restraint
- Bang & Olufsen product polish

It must never look:

- Edgy
- Horror-driven
- Satanic or demonic
- Like generic game fantasy
- Loud, neon, RGB, or cyberpunk
- Anime, cartoon, or mascot-led

## Product Surfaces

The same visual language must apply to:

- Logo
- Boot splash
- GRUB theme
- Plymouth theme
- SDDM theme
- KDE Plasma theme
- Icon pack
- Cursor theme
- Lock screen
- Wallpaper set
- Terminal theme
- Firefox theme and homepage
- Dolphin defaults
- Calamares installer
- Website
- Documentation
- Community spaces
- Merchandise

## Brand Rule

The logo carries the brand. GnegnoliOS does not need a mascot.
